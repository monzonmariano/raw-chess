# Raw Chess ♟️

A lightweight, responsive mobile chess application built for Android. This project features a clean, distraction-free user interface and integrates a high-performance local AI engine for offline gameplay.

## 🚀 Features
* **Local AI Engine:** Play against an integrated instance of Stockfish completely offline.
* **Responsive UI:** Tailored grid layouts designed specifically for mobile screen form factors.
* **Ad-Free Experience:** Focus purely on the game with zero monetization or telemetry overhead.
* **Clean Architecture:** Developed with decoupled modules for rendering logic and state management.

## 📦 Production Pipeline
The application is currently navigating the Google Play Console testing framework, utilizing automated community testing tracks to fulfill verification compliance before full production rollout.
